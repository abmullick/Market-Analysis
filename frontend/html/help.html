The ranking page surfaces the three highest-scoring funds in a dedicated strip above the table. Each card shows the fund name, AMC, overall score, and a "Why?" button that explains the strengths and trade-offs behind its rank.

How Ranking Works

The ranking sidebar shows a live "How ranking works" panel. The four metric groups (Performance, Risk-Adjusted, Risk, Consistency) display their current weights as bars and a total active weight, derived from the active preset or your custom criteria.

Why This Fund Ranks Here

Every row in the ranking table, the top-3 cards, and the Fund Details page exposes the underlying component scores. The "Why?" dialog highlights the fund's top two strengths and bottom two trade-offs, with score and weight for each. These are derived directly from the fund's normalized ranking scores.

Screening & Filters

Apply filters such as AUM, fund age, and plan/option type before ranking. Filters are combined with AND logic and show match counts in the summary. Active filters appear as removable chips below the summary with a "Clear All" action.

Methodology

Returns are calculated from NAV history using simple period returns and CAGR. Risk metrics use sample-standard-deviation annualized with 252 trading days. Percentile ranks include only funds with valid data for that specific metric. Rankings normalize raw values to a 0–100 score; lower-is-better metrics are inverted.

Mutual Fund Portfolio Builder

Build Workflow

1. Search and select mutual funds from the full AMFI universe.
2. Add multiple funds to your portfolio (2 to 10 funds).
3. Remove funds or change selections at any time; selections persist in your browser session.
4. Assign an allocation percentage to each fund.
5. Ensure the total allocation equals exactly 100%.
6. Run the portfolio analysis.
7. Review portfolio-level performance and risk metrics.
8. Review the Portfolio Health Score.

Allocation Rules

Each allocation is a percentage from 0 to 100 with up to two decimal places. The total across all funds must equal exactly 100% before the analysis button is enabled. Funds with 0% allocation are kept visible in the result but do not contribute to the portfolio calculation. A minimum of two contributing funds is required to run the analysis.

Portfolio Analysis Methodology

The analysis combines your selected funds and their portfolio weights rather than treating each fund independently. Individual fund daily returns are combined using the selected weights over the common dates shared by all contributing funds — the intersection of their published NAV dates, with no interpolation or forward-filling. Zero-weight funds do not contribute. The resulting portfolio return series (base 100) drives portfolio-level CAGR, annualized volatility, maximum drawdown, Sharpe and Sortino calculations, all computed with the same primitives used for single-fund metrics.

Return Contribution

The Return Contribution section answers “which funds contributed most to my portfolio’s return?”. For each contributing fund it shows the fund’s Fund Return — its own standalone return over the portfolio’s common analysis period — and its Contribution to Portfolio Return, expressed in percentage points (pp). These are different quantities: contribution is calculated from the existing portfolio daily-return methodology — each fund’s daily weighted return (target allocation × fund daily return) scaled by the portfolio’s cumulative growth factor — so allocation, rebalancing, and compounding are all reflected. Contributions are additive and reconcile to the portfolio’s overall return over the common period within rounding tolerance. Negative contributions are funds that detracted from portfolio performance. Zero-allocation funds are excluded, consistent with their exclusion from all portfolio calculations. Contribution does not feed into the Portfolio Health Score.

Drawdown & Recovery

Drawdown measures the decline from a previous portfolio high: drawdown(t) = value(t) / running-peak(t) − 1 on the portfolio’s growth series (the same series and convention used by the existing Maximum Drawdown metric). Maximum Drawdown is the deepest such decline over the analysis period. A drawdown episode begins when the portfolio moves below its previous high and ends when it reaches or exceeds that high again. For each episode the section shows the peak date, trough date, recovery date, magnitude, and durations measured in calendar days (elapsed time, not the number of trading observations). An episode still below its previous high at the end of the analysis period is marked Ongoing: no recovery date is claimed, and the Current Drawdown plus status (Still recovering / At a new high) reflect the last observation. Recovery can take much longer than the decline itself because regaining a peak requires recovering the full percentage loss while the base is smaller. Episodes shallower than 2% are not listed, and at most the five deepest episodes are shown; the summary Maximum Drawdown always covers all episodes and reconciles with the existing metric. This analysis does not affect the Portfolio Health Score.

Rolling Performance

The Rolling Performance section shows how the portfolio's rolling CAGR was distributed across many overlapping historical windows, answering “how consistently has this portfolio generated returns across different periods?”. For each window ending on an observation date, the annualized return (CAGR) is computed from the portfolio’s existing growth series — the same common-period daily-return methodology used by every other section — so no new data or calculation engine is introduced. The 1-Year, 3-Year, and 5-Year windows reuse the same calendar-year conventions as the existing rolling-consistency calculation.

For each available window the section shows the number of observations, average and median rolling CAGR, the best and worst rolling periods, and the percentage of rolling periods with a positive return. A chart displays rolling CAGR (%) over time with the zero line (breakeven) marked; the series can be switched between 1-Year, 3-Year, and 5-Year windows.

This is distinct from Portfolio CAGR, which is the single annualized return over the entire analysis period. Rolling CAGR shows the distribution of historical period returns, not a prediction of future performance. If the portfolio does not have enough history for a given window, that window displays “Insufficient history” rather than a fabricated value. This analysis does not affect the Portfolio Health Score.

Portfolio Health Score

The Health Score is a 0–100 portfolio-level diagnostic, not a prediction of future returns. It blends five components: Return Quality (25%), Downside Risk (25%), Risk-Adjusted Return (20%), Allocation Concentration (20%), and Fund Mix (10%).

Health Score Components

Return Quality (25%) — portfolio CAGR contribution plus rolling-return consistency and stability across 1Y/3Y/5Y windows.
Downside Risk (25%) — maximum drawdown depth and downside deviation relative to overall volatility.
Risk-Adjusted Return (20%) — the portfolio Sortino ratio.
Allocation Concentration (20%) — a Herfindahl-Hirschman Index (HHI) over fund weights; more evenly distributed allocations score better.
Fund Mix (10%) — a portfolio-level diversification proxy based on category spread and AMC spread (blended 60/40).

Health Score Confidence

The score is classified by how much common portfolio history is available: High (≥ 5 years), Good (≥ 3 and < 5 years), Limited (≥ 1 and < 3 years), and Low (< 1 year). When the available history is less than one year, the score is withheld entirely and the portfolio shows an insufficient-history notice instead.

Health Score Edge Cases

Single-fund portfolios score 0 on Allocation Concentration and Fund Mix, since those components require at least two funds.
Unavailable components are excluded and the remaining available component weights are re-normalized, so a partial score is still shown when some data is missing.
Legacy schemes (funds whose AMFI-reported NAV publication lags the newest NAV in the universe by more than 14 days) cap confidence at Limited even when the history is otherwise long enough for a higher tier.

Fund Details & Scheme Variants

Fund Details Modal

Open any fund to inspect identity badges (AMC, category, plan, option), inception and fund age, 1Y/3Y/5Y/10Y returns, Sharpe/Sortino ratios, annualized volatility, maximum drawdown, downside deviation, rolling-return consistency, category-relative percentile analysis, drawdown charts, historical NAV, asset allocation and top holdings.

Scheme Variants

A mutual fund family can have multiple scheme variants that share the same underlying portfolio but differ in how they are sold and how returns are credited. The Fund Details modal shows two labels: Plan (“Direct” or “Regular”) and Option (“Growth” or “IDCW”). The underlying scheme code identifies the specific variant, so each variant is analyzed independently from its own NAV history.

Legacy Schemes

What “Legacy” Means

A Legacy designation means the fund’s AMFI-reported last NAV publication date lags the newest NAV date in the AMFI universe by more than 14 days. It is an AMFI-reported lifecycle signal, not an inference from NAV-history length. A Legacy designation does not automatically mean the historical data is invalid.

Impact on Analysis

Legacy schemes appear in search results after current schemes, so they are distinguishable. In the Portfolio Builder, a contributing Legacy fund caps the Health Score confidence at Limited, even when the common history is otherwise long enough for a higher tier. Fund Details and ranking continue to use whatever NAV history is available for the scheme.

Metrics Reference

Every number shown in Ranking, Fund Details, and Category-Relative Analysis comes from these building blocks. Click a metric to expand its formula, example, and usage.

Definition

Simple percentage return over the most recent ~365 calendar days using available NAV history.

Formula

1Y Return = (NAV_end / NAV_start) - 1

NAV_end = latest available NAV in the lookback window.
NAV_start = NAV closest to 365 calendar days before NAV_end.

Example

NAV_start = 100.00, NAV_end = 116.44 → 1Y Return = 0.1644 → 16.44%.

Use

Shows near-term performance. Used in ranking presets like Highest Returns and Best Overall.

Definition

Compound annual growth rate over approximately 3 calendar years of NAV history.

Formula

CAGR = (NAV_end / NAV_start)^(1 / years) - 1

years = calendar days between NAV_start and NAV_end divided by 365.25.

Example

NAV_start = 100.00, NAV_end = 157.41 over ~3 years → CAGR ≈ 0.2146 → 21.46%.

Use

Measures medium-term growth. Heavily weighted in Best Overall and Highest Returns presets.

Definition

Compound annual growth rate over approximately 5 calendar years of NAV history.

Formula

CAGR = (NAV_end / NAV_start)^(1 / years) - 1

Example

NAV_start = 100.00, NAV_end = 217.56 over ~5 years → CAGR ≈ 0.1756 → 17.56%.

Use

Reflects longer-term performance stability. Included in Highest Returns and Best Overall presets.

Definition

Compound annual growth rate over approximately 10 calendar years of NAV history.

Formula

CAGR = (NAV_end / NAV_start)^(1 / years) - 1

Example

Only shown when a fund has at least ~10 years of NAV history. Otherwise displayed as Not available.

Use

Useful for evaluating long-tenured funds. Appears in Highest Returns preset with smaller weight.

Definition

Return earned per unit of total volatility (risk). Uses a fixed risk-free rate of 4%.

Formula

Sharpe = (Annualized Return - Risk Free Rate) / Annualized Volatility

Annualized Return = geometric return over the full NAV history.
Annualized Volatility = sample std dev of daily returns × √252.
Risk Free Rate = 0.04 (4%).

Example

Annualized Return = 12%, Volatility = 16.61% → Sharpe = (0.12 - 0.04) / 0.1661 ≈ 1.35.

Use

Primary risk-adjusted metric. Higher Sharpe means more return per unit of total risk. Core to Best Overall, Lowest Risk, and Best Consistency presets.

Definition

Like Sharpe, but penalizes only downside volatility. Better for evaluating funds where upside volatility is desirable.

Formula

Sortino = (Annualized Return - Risk Free Rate) / Downside Deviation

Downside Deviation = √( Σ(min(r_t, 0)^2) / N ) × √252
Only negative daily returns contribute to the denominator.

Example

Annualized Return = 12%, Downside Deviation = 12.15% → Sortino = (0.12 - 0.04) / 0.1215 ≈ 1.85.

Use

Used alongside Sharpe in Best Overall and Best Consistency presets. Sortino > Sharpe usually indicates positive skewness.

Definition

Standard deviation of daily returns, annualized to a yearly figure. Measures overall NAV fluctuation.

Formula

Volatility = SampleStdDev(daily_returns) × √252

daily_return_t = (NAV_t / NAV_{t-1}) - 1
SampleStdDev uses N-1 denominator.
252 = typical trading days per year.

Example

Daily returns std dev ≈ 1.047% → Volatility = 0.01047 × √252 ≈ 16.61%.

Use

Core risk measure. Lower volatility implies more stable returns. Used in Lowest Risk preset and as a counterbalance in Best Overall.

Definition

The largest percentage drop from any historical peak NAV to any subsequent trough before recovery.

Formula

Max Drawdown = max( (peak - trough) / peak )

peak = highest NAV seen so far while iterating forward.
trough = lowest NAV after that peak.

Example

Peak = 120.00, trough = 91.20 → Drawdown = (120 - 91.2) / 120 = 0.24 → 24.00%.

Use

Shows worst historical loss from a peak. Lower is better. Used in Lowest Risk preset.

Definition

Standard deviation of negative returns only, annualized. Ignores upside surprises.

Formula

Downside Dev = √( Σ(min(r_t, 0)^2) / N ) × √252

r_t = daily return.
Only negative or zero returns enter the sum.
N = total number of daily returns.

Example

Sum of squared negative returns / N = 0.000233 → √0.000233 × √252 ≈ 12.15%.

Use

Used in Sortino and as an independent risk measure. Lower downside deviation means fewer/smaller negative periods.

Definition

Percentage of overlapping 1-year rolling windows that produced positive returns.

Formula

Positive % = Count(positive 1Y windows) / Count(all 1Y windows) × 100

A 1Y window = NAV at day t divided by NAV at day t-365.
Windows are overlapping and computed for every valid observation date.

Example

41 valid 1Y windows, 35 positive → 35 / 41 × 100 = 85.37%.

Use

Measures consistency, not just magnitude. A fund can have high returns with low consistency if returns are volatile. Used in Best Consistency and Best Overall presets.

Definition

A 0–100 composite score derived from weighted normalized metrics across the selected category.

Formula

Overall Score = Σ ( Metric Score_i × Weight_i )

Metric Score = normalized 0–100 value for that metric across all category peers.
Weight = user-selected or preset weight, normalized to sum to 100.
Lower-is-better metrics are inverted so 100 always means best.

Example

1Y Return score = 80, weight = 25%; Sharpe score = 90, weight = 20%; Volatility score = 60, weight = 15% → Overall = 80×0.25 + 90×0.20 + 60×0.15 + ... = score out of 100.

Use

Ranks funds from best to worst within a category. The top-ranked fund has the highest overall score.

Scoring & Percentiles

Formula

Score = (value - min) / (max - min) × 100

If direction is lower-is-better, the score is inverted: 100 - Score.
If all peers have the same value, every fund receives 100.

Example

Category returns range from 10% to 20%. A fund with 16.44% scores = (0.1644 - 0.10) / (0.20 - 0.10) × 100 ≈ 64.4.

Formula

Percentile = (Count(values ≤ fund_value) / Count(valid peers)) × 100

For lower-is-better metrics: Count(values ≥ fund_value).
Peers with missing data for that metric are excluded.

Example

Fund A = 16.44%, peers = 41 valid values, 27 funds below or equal → 27/41 × 100 = 65.9th percentile.

Formula

Rank = 1 + Count(peers with strictly better value)

Higher-is-better: count peers with value > fund_value.
Lower-is-better: count peers with value < fund_value.

Example

Fund A = 16.44%. 26 funds have higher 1Y Return → Rank = 1 + 26 = 27th of 41.

Using Metrics in Fund Details

What you see

A card grid showing 1Y Return, 3Y CAGR, 5Y CAGR, 10Y CAGR, Sharpe Ratio, Sortino Ratio, Volatility, Max Drawdown, and Downside Deviation. Values are raw calculated numbers, not scores.

How to read it

Returns and ratios are shown as decimals converted to percentages (e.g., 0.1644 → 16.44%). Sharpe and Sortino are shown as unitless ratios (e.g., 1.35). Volatility, drawdown, and downside deviation are shown as percentages.

Example

A fund with 1Y Return = 16.44%, Sharpe = 1.35, Volatility = 16.61% means it delivered strong recent returns with moderate risk.

What you see

Cards for 1Y, 3Y, and 5Y rolling windows showing positive return percentage, number of windows, and a chart of rolling CAGR over time.

How to read it

Positive % close to 100% means the fund almost always produced gains over that rolling window. A chart with many peaks and troughs indicates inconsistent period-to-period performance.

What you see

A table with Metric, Fund Value, and Category Position. Position includes wording like "Top 1%", ordinal rank (e.g., 2nd of 27), exact percentile (e.g., 96.3rd percentile), and a visual bar.

How to read it

Fund Value is the raw metric. Category Position tells you how the fund stands among peers with valid data for that metric. A high percentile with a low ordinal rank means the fund is near the top of its category.

Example

5Y CAGR = 17.56%, 2nd of 27, 96.3rd percentile means only 1 fund in the category had a higher 5Y CAGR.

What you see

A chart showing NAV peak-to-trough declines over time, plus summary stats like maximum drawdown and recovery time.

How to read it

Deeper and longer drawdowns indicate higher historical risk. A fund that recovers quickly after a decline may be more resilient than one that takes years to recover.

Using Metrics in Comparison

What you see

A table with one row per metric and one column per selected fund. Shows raw values for returns, ratios, volatility, drawdown, downside deviation, and consistency.

How to read it

Compare raw values directly. For returns and ratios, higher is better. For volatility, drawdown, and downside deviation, lower is better. Consistency shows positive rolling window percentages.

Example

Fund A: 1Y Return = 16.44%, Sharpe = 1.35, Volatility = 16.61%. Fund B: 1Y Return = 14.20%, Sharpe = 1.10, Volatility = 18.05%. Fund A is better on all three dimensions.

What you see

A scatter plot with annualized return on one axis and annualized volatility on the other. Each fund is a point.

How to read it

Funds in the top-left quadrant are ideal: high return, low risk. Funds in the bottom-right are less desirable: low return, high risk. Distance from the origin indicates risk-adjusted efficiency.

What you see

Overlaid drawdown charts for all selected funds, showing peak-to-trough declines over time.

How to read it

Deeper shaded areas mean larger losses from peaks. A fund with consistently shallow drawdowns is more risk-tolerant. Look for funds that recover quickly after declines.

What you see

Overlaid rolling CAGR time series for the selected window period (1Y, 3Y, or 5Y).

How to read it

Smoother lines indicate more consistent rolling returns. Frequent large swings suggest the fund's performance is volatile over time. Compare the average level and stability across funds.

Data Transparency & Freshness

The application makes every date explicit so that you can judge how current and how comparable each piece of data is. Dates shown always come from the underlying API; nothing is fabricated.

Data as of

The latest NAV observation date for a fund. On the Ranking page this is the maximum nav_date across the ranked set; on the Fund Details header it is the fund's own data_end_date. Displayed as DD MMM YYYY.

History from / Coverage

Fund Details shows a compact history range and data point count (e.g., 02 Jan 2013 → 01 Sep 2026 · 3,300 pts) so you can see why a 10Y metric may exist for one fund but not another.

Calculation Periods

Each KPI card on the Fund Details page carries a small period label (3Y, 5Y, Full history). The Performance Summary table explicitly distinguishes simple 1Y returns from CAGR for longer periods.

Not Available — Why?

"Not available" values are accompanied by a tooltip explaining the reason when it can be derived from the data: Insufficient history (fund age shorter than the required period), Insufficient data points (fewer than 2 NAV records), or Data unavailable (the provider returned no value).

Comparison Period

A compact strip at the top of the Compare Funds view shows the common overlapping window across the selected funds (max(starts) → min(ends)), with a year-range hint. When the common period is narrower than the union, a subtle Some funds have shorter histories pill explains the overlap.

No Invented Freshness Threshold

The application does not define a "data is stale" threshold, so dates are shown without an arbitrary warning class. A soft green dot next to "Data as of" simply indicates the record is from the current dataset.

Data Sources & Caching

Mutual fund data is sourced from MFAPI (scheme metadata and on-demand NAV history) and TigZig (a pre-computed batch NAV dataset that supplies AUM, first NAV date, and per-fund NAV history for the full lookback window). The CRITERIA_LOOKBACK_YEARS map determines how much history is fetched for the active criteria.

Caching is layered:

  • Per-fund metric cache keyed by (scheme_code, lookback_years) — avoids recomputing identical metric payloads.
  • Category-level cache for percentile results, refreshed on data source changes.
  • Default TTL of 24 hours for category percentile results.

Architecture

The platform follows a layered architecture: Frontend → FastAPI Routes → Services → Models → External Providers. Stock Analysis, Stock Portfolio Builder, Mutual Fund Analysis, and Mutual Fund Portfolio Builder are isolated modules. AI insights are provided via Groq and are interpretation-only; they do not compute scores or fetch data.
